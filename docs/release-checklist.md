# 첫 배포 검토

실제 npm 업로드는 사용자 승인 전까지 보류합니다.

| 항목 | 1.x | 2.x |
| --- | --- | --- |
| 버전 | 1.0.0 | 2.0.0 |
| 유지 브랜치 | 1.x | main (준비: codex/release-2.x) |
| npm 태그 | legacy | latest |
| 기존 테스트 | 확인 중 | 로컬 Node 24 통과 |
| tarball React/Next 설치·진단·수정 | 확인 중 | 로컬 Node 24 통과 |
| 최소 Node 검증 | 확인 중 | 확인 중 |
| npm scope 권한 | 사용자 확인 중 | 사용자 확인 중 |
| 사용자 배포 승인 | 대기 | 대기 |
| 실제 npm 배포 | 미실행 | 미실행 |

승인 시에는 최종 패키지명, 브랜치 커밋, tarball 구성과 검증 결과를 함께 확인합니다. 현재 기록은 준비 중인 상태이며 배포 완료를 의미하지 않습니다.
